# GenAI Learning Practicals 🤖

Hands-on Generative AI practicals covering LLMs, prompt engineering, structured outputs, embeddings, RAG, vector databases, document retrieval, and AI agents.

This repository documents my practical learning journey while building GenAI applications using Python, LangChain, LLM APIs, Hugging Face models, Groq, Gemini, and other GenAI tools.
